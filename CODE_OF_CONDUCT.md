# Code of conduct

We are committed to a welcoming, harassment-free community for everyone. Be respectful, assume good intent, give actionable technical feedback and protect other people's privacy.

Unacceptable behavior includes harassment, discrimination, threats, publishing private information, or using project channels to solicit credentials or financial activity. Maintainers may edit or remove contributions and temporarily or permanently ban participants whose behavior is inappropriate.

Report conduct issues privately to the repository owner through GitHub. This policy is adapted from the Contributor Covenant 2.1; see <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
